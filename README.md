# IE1005-Mini-Project

## Project Description

This data science and machine learning mini project investigates whether a Netflix title's genre and description can predict its age rating. Using the Netflix Movies and TV Shows dataset, we will explore the data, prepare the relevant features, and develop a classification model to predict age-rating categories.

The project follows the IE0005 mini-project brief: define an interesting problem, use exploratory data analysis and visualization to understand the dataset, prepare the data for the chosen problem, and apply machine learning to address it. The work should demonstrate learning beyond the course and clearly identify each team member's contributions.

## Main Research Question

**How well can a Netflix title’s genre and description predict its age rating?**

- **Input features:** Genre and description.
- **Target variable:** Age rating.
- **Problem type:** Classification.

## Dataset

[Netflix Movies and TV Shows — Kaggle](https://www.kaggle.com/datasets/shivamb/netflix-shows/data)

## Planned Work

1. Explore the dataset and visualize relevant patterns.
2. Clean and prepare the genre, description, and age-rating data.
3. Develop and evaluate a classification model, exploring Naive Bayes as proposed in the project notes.
4. Present the findings through visualizations, slides, and a project demonstration.

## Course Requirements

- Work in a team of four or fewer students.
- Demonstrate an interesting objective, data exploration, data preparation, machine learning, and learning beyond the course.
- Deliver an eight-minute presentation followed by five minutes of Q&A, clearly stating who contributed each portion.
- Submit a single ZIP containing the code, data used, presentation slides, and references to resources used.
